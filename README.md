## Project Setup 
Follow the steps below to set up and run the application locally: 
 
1. Clone this repository to your local machine. 
2. Run the server using `npm start`. 
3. Go to `http://localhost:3000` in your browser. 
 
## Features
- **User Registration**: Allows users to create an account using 
their email.
- **Login**: Secure user login with email-based authentication.
- **Password Reset**: Users can reset their password through an email 
link. 
 
## Requirements 
Node.js and MongoDB are required to run this application.
